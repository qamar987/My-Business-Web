# Electrician Services Website

A modern, responsive website for a professional electrician service provider, offering complete electrical solutions for homes, new constructions, and businesses.

## 🔌 About

This website showcases electrician services, allows customers to browse available services, view completed work, and contact the business for bookings, quotes, and emergency repairs.

## ✨ Features

- Responsive design (mobile, tablet, desktop)
- Services overview with detailed descriptions
- About Us section highlighting experience and credentials
- Portfolio/Gallery of completed electrical work
- Customer testimonials
- Contact form with service selection
- Click-to-call and WhatsApp integration
- Google Maps location embed

## 🛠️ Services Offered

- Full house electrical wiring (new construction)
- Complete electrical system installation for new homes
- House rewiring (old wiring replacement)
- Circuit breaker & panel installation/repair
- Switchboard & distribution board installation
- Fan, light & fixture installation
- Socket & switch installation/repair
- Electrical fault finding & troubleshooting
- Short circuit repair
- Voltage fluctuation issues
- Earthing/grounding installation & repair
- Generator & UPS wiring/installation
- Inverter installation & wiring
- Solar panel wiring setup
- Electrical safety inspection
- Commercial electrical wiring
- Emergency electrical repair (24/7)
- General electrical maintenance
- Appliance wiring (AC, geyser, kitchen appliances)
- Custom electrical complaints/requests

## 🚀 Tech Stack

- Built with [Google AI Studio](https://aistudio.google.com/)
- Deployed on Google Cloud Run

## ⚙️ Environment Variables

This project was scaffolded using AI Studio's default template, which includes the following environment variables:

| Variable | Description |
|---|---|
| `GEMINI_API_KEY` | API key for Gemini AI calls (not actively used in this project unless AI-powered features are added) |
| `APP_URL` | The deployed Cloud Run service URL, auto-injected at runtime |

> Note: This project currently does not use any AI-powered features, so `GEMINI_API_KEY` is not required for the site to function.

## 📦 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/qamar987/My-Business-Web.git
   cd My-Business-Web
   ```
2. Install dependencies
   ```bash
   npm install
   ```
3. Run locally
   ```bash
   npm run dev
   ```
